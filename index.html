Project Evo

A personal research experiment that applies the principles of evolution to AI-made content.

What it does

Project Evo runs a small number of YouTube channels owned by the project's owner. Each channel is operated by its own AI agent, which plans, produces, uploads, and manages that channel's videos with as little human input as possible.

A separate scoring program reads each channel's YouTube Analytics and awards points based on performance. The highest-scoring channel moves on to the next round of testing.

Why it asks for access to YouTube accounts

Project Evo uses YouTube API Services. It asks for access only to the owner's own channels, so that:

  • each AI agent can upload and manage videos, playlists, captions, and comments on its own channel, and
  • the scoring program can read each channel's analytics, with read-only access.

Project Evo is not offered to the public and does not access anyone else's account.
