Privacy Policy

Project Evo · Last updated October 6, 2026

Overview

Project Evo is a personal research experiment that operates YouTube channels owned by the project's owner using AI agents. This policy explains what data Project Evo accesses, how it is used, and how access can be revoked.

YouTube API Services

Project Evo uses YouTube API Services. By using Project Evo, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data we access

With the account holder's permission, Project Evo accesses:

  • channel information, such as the channel ID, name, and settings;
  • the channel's videos, playlists, captions, and comments, so the channel's agent can upload and manage content;
  • YouTube Analytics reports, such as views, watch time, subscribers, and engagement, so channels can be scored.

Project Evo only accesses channels owned by the project's owner. It does not access other users' accounts or private data.

How we use data

  • To publish and manage videos on the owner's channels.
  • To score each channel's performance and record the results of the experiment.
  • To let the AI agents decide what content to make. For this, channel and analytics data may be sent to an AI model provider (Anthropic's Claude API) for processing.

Project Evo does not sell data, use it for advertising, or share it with anyone other than the AI model provider described above.

Storage and security

Access tokens and data are stored on the owner's own computer, in a location that is not synced to cloud storage. Project Evo does not use cookies and does not store information on visitors' devices. Data is kept only as long as needed to run and record the experiment, and is deleted when it is no longer needed.

Google API Services User Data Policy

Project Evo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke Project Evo's access to a Google account at any time on the Google security settings page. Data already stored can be deleted on request.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions about this policy can be sent by opening an issue at github.com/athenuem-admin/athenuem-admin.github.io/issues.
